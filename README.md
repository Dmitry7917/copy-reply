# copy-reply

Мод для Claude Code: кнопка `⧉ copy` в правом нижнем углу каждого блока ответа. Нажатие копирует текст блока в буфер обмена (в markdown) и показывает «Ответ скопирован»; если не вышло, уведомление скажет почему.

Кнопка нажимается мышью в полноэкранном режиме терминала (`"tui": "fullscreen"`), на desktop — как обычная кнопка. Под свёрнутыми сводками кнопки нет.

Ограничение: Claude Code передаёт моду каждый текстовый блок отдельно, поэтому кнопка есть и под промежуточными фразами между вызовами инструментов, а копирует только свой блок. Весь последний ответ целиком копирует встроенная команда `/copy`.

## Установка

```
/plugin marketplace add Dmitry7917/copy-reply
/plugin install copy-reply@copy-reply
```
